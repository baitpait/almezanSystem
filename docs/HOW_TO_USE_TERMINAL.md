# كيفية استخدام Terminal على macOS

## ما هو Terminal؟

Terminal (سطر الأوامر) هو برنامج على macOS يسمح لك بتنفيذ الأوامر مباشرة على جهازك. جميع الأوامر مثل `brew install composer` يجب تنفيذها هنا.

---

## كيفية فتح Terminal

### الطريقة 1: من Spotlight Search (الأسرع)

1. اضغط على **Command + Space** (⌘ + Space)
2. اكتب **Terminal**
3. اضغط **Enter**

### الطريقة 2: من Finder

1. افتح **Finder**
2. اذهب إلى **Applications** (التطبيقات)
3. افتح مجلد **Utilities** (الأدوات المساعدة)
4. انقر نقراً مزدوجاً على **Terminal**

### الطريقة 3: من Launchpad

1. اضغط على **F4** أو اسحب بأربعة أصابع لأعلى على Trackpad
2. ابحث عن **Terminal**
3. انقر عليه

## كيفية استخدام Terminal

### 1. فتح Terminal

بعد فتح Terminal، سترى نافذة سوداء أو بيضاء مع سطر مثل هذا:

```
your-username@your-computer-name ~ %
```

### 2. نسخ الأوامر

**الطريقة الصحيحة:**

1. **انسخ الأمر** من الملف (مثل `brew install composer`)
2. **ارجع إلى Terminal**
3. **الصق الأمر** باستخدام:
   - **Command + V** (⌘ + V)
   - أو انقر بزر الماوس الأيمن واختر **Paste**
4. اضغط **Enter** لتنفيذ الأمر

### 3. مثال عملي

لنفترض أنك تريد تثبيت Composer:

1. افتح Terminal
2. انسخ هذا الأمر: `brew install composer`
3. الصق الأمر في Terminal (Command + V)
4. اضغط Enter
5. انتظر حتى ينتهي التثبيت

## نصائح مهمة

### ✅ افعل هذا:

- **انسخ الأمر كاملاً** من الملف
- **الصق في Terminal** ثم اضغط Enter
- **انتظر** حتى ينتهي الأمر قبل تنفيذ الأمر التالي
- **اقرأ الرسائل** التي تظهر في Terminal

### ❌ لا تفعل هذا:

- لا تكتب الأوامر في أي مكان آخر (مثل TextEdit أو Notes)
- لا تنسخ الرموز الخاصة مثل `$` أو `#` في بداية الأمر
- لا تضغط Enter قبل أن تنتهي من نسخ الأمر كاملاً

## رموز مهمة في الأوامر

### `#` - تعليق (لا تنسخه)

```bash
# هذا تعليق - لا تنسخ هذا السطر
brew install composer  # هذا هو الأمر الفعلي
```

**انسخ فقط:** `brew install composer`

### `$` - في بعض الأوامر (عادة لا تنسخه)

```bash
$ php -v
```

**انسخ فقط:** `php -v`

### ```bash - بداية كود (لا تنسخه)

```bash
brew install composer
```

**انسخ فقط:** `brew install composer`

## حل المشاكل

### المشكلة: لا يظهر شيء عند الصق

**الحل:**
- تأكد من أن Terminal مفتوح ونشط
- جرب **Command + V** مرة أخرى
- أو انقر بزر الماوس الأيمن واختر **Paste**

### المشكلة: ظهر خطأ "command not found"

**الحل:**
- تأكد من أنك نسخت الأمر بشكل صحيح
- تأكد من عدم وجود مسافات إضافية
- تأكد من أن البرنامج المطلوب مثبت (مثل Homebrew)

### المشكلة: يطلب كلمة مرور

**الحل:**
- اكتب كلمة مرور Mac الخاصة بك
- لن تظهر الأحرف عند الكتابة (هذا طبيعي)
- اضغط Enter بعد إدخال كلمة المرور

## خطوات التثبيت الكاملة (مثال)

### الخطوة 1: تثبيت Homebrew

1. افتح Terminal
2. انسخ هذا الأمر:
   ```
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```
3. الصق في Terminal (Command + V)
4. اضغط Enter
5. انتظر حتى ينتهي التثبيت (قد يستغرق بضع دقائق)

### الخطوة 2: تثبيت PHP

1. في نفس Terminal
2. انسخ: `brew install php@8.2`
3. الصق واضغط Enter
4. انتظر حتى ينتهي التثبيت

### الخطوة 3: تثبيت Composer

1. في نفس Terminal
2. انسخ: `brew install composer`
3. الصق واضغط Enter
4. انتظر حتى ينتهي التثبيت

## نصائح إضافية

### 1. فتح Terminal جديد

إذا أردت فتح Terminal جديد:
- **Command + T** (في نفس النافذة)
- أو **Command + N** (نافذة جديدة)

### 2. إغلاق Terminal

- **Command + Q** (إغلاق كامل)
- أو انقر على X في الزاوية

### 3. مسح الشاشة

- اكتب: `clear`
- أو **Command + K**

### 4. إيقاف أمر يعمل

- اضغط **Control + C** (⌃ + C)
