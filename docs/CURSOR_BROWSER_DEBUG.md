# لماذا المتصفح داخل Cursor لا يعرض أخطاء Laravel؟

## السبب
المتصفح المدمج في Cursor (Simple Browser / Embedded Browser) يعرض محتوى الصفحة فقط. في كثير من الأحيان:
- **صفحات الخطأ من Laravel** (مثل 500 أو استثناء PHP) قد لا تظهر بالكامل أو تظهر كصفحة فارغة.
- **محتوى الاستجابة** قد يُقصّ أو لا يُعرض كامل HTML (مثل صفحة الـ debug).

لذلك لا تعتمد على متصفح Cursor وحده لرؤية رسالة الخطأ.

## كيف ترى المشكلة؟

1. **افتح الموقع في متصفح خارجي** (Chrome, Firefox, Safari) على نفس الرابط، مع تشغيل السيرفر محلياً:
   ```
   http://127.0.0.1:8000/medical-report/25
   ```
   عادةً ستظهر صفحة الخطأ الكاملة إذا كان `APP_DEBUG=true` في `.env`.

2. **راجع سجل Laravel:**
   ```bash
   tail -f storage/logs/laravel.log
   ```
   ثم أعد تحميل الصفحة؛ أي استثناء سيُسجّل هنا.

3. **تأكد من تفعيل العرض التفصيلي للأخطاء في `.env`:**
   ```
   APP_DEBUG=true
   ```

4. **تشغيل اختبار من الطرفية:**
   ```bash
   php artisan tinker --execute="
   \$a = \App\Models\Appointment::with(['patient','doctor','operation'])->find(25);
   var_dump(\$a ? \$a->toArray() : 'not found');
   "
   ```

## بعد التعديل الأخير
تمت إضافة معالجة أخطاء في صفحة التقرير الطبي: عند حدوث خطأ أو عدم وجود موعد/صلاحية، ستظهر **رسالة واضحة داخل الصفحة** بدلاً من صفحة فارغة، حتى في متصفح Cursor.
